# TaskWizard
A task management web app to create, edit, and delete tasks.  

### 🚀 Features
- Add, update, delete tasks  
- Mark tasks as completed  
- Responsive design (mobile-first)  

### 🛠️ Tech Stack
- React.js  
- Tailwind CSS  
- Node.js + Express  
- MongoDB
